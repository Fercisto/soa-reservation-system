# SOA Reservation System

A service-oriented reservation system developed as an academic project to demonstrate Service-Oriented Architecture (SOA), service interoperability, and communication between services built with different programming languages and technologies.

## Overview

The system is designed as a set of independent services, where each service is responsible for a specific business function.

The main purpose of the project is to demonstrate how different technologies can work together as part of a distributed system.

## Services

* Authentication Service
* User Service
* Reservation Service
* Room Service
* Payment Service
* Notification Service

## Technologies

Different services will use different programming languages and frameworks according to their responsibilities.

The project may include:

* PHP / Laravel
* JavaScript / Node.js
* Python / FastAPI
* Java / Spring Boot
* React
* RabbitMQ
* REST APIs
* JSON

## Architecture

Each service is developed independently and communicates with other services through defined interfaces and protocols.

The project focuses on:

* Service independence
* Interoperability
* RESTful communication
* Separation of responsibilities
* Communication between different technologies
* Distributed application architecture
